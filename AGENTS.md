# Project Rules

- Keep the quiz self-contained in `index.html`; do not add a server, build step, or runtime dependency.
- Preserve the space-exploration visual style, narrow centered layout, responsive behavior, and light/dark theme support.
- Keep quiz content and interaction logic accessible: use semantic native controls, visible keyboard focus, readable contrast, and clear status feedback.
- When changing quiz behavior, verify answer selection, score/progress updates, feedback states, results, replay, and keyboard navigation in the integrated browser.
- Prefer small, focused edits and avoid unrelated changes.
